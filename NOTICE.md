## Third-party assets from the official dashboard

### Files kept byte-for-byte from upstream

The following are copied unmodified from <https://mimo.xiaomi.com/rl/> and are kept only
so the telemetry layer can be diffed against the live site:

- `data/upstream/**` (the pristine reference copy)
- `site/style.css`
- `site/js/app.js`
- `site/js/charts.js`
- `site/js/format.js`
- `site/js/theme.js`
- `site/fonts/`

### Files derived from upstream but modified by this project

`site/index.html` **started** as the upstream page shell but is no longer unmodified: this
project added the telemetry stylesheet and script tags (marked with `[telemetry]` comments)
and social-share meta tags. The upstream markup it is based on remains the property of
Xiaomi MiMo; the additions are this project's.

`site/offline.html` is generated by `src/export.ts` from `site/index.html` plus the offline
bundle, so it inherits both.

### Data

The training metrics, notices and benchmark figures contained in `data/store/` and
`content/` are read from the public dashboard API at <https://mimo.xiaomi.com/rl/> and
remain the property of the Xiaomi MiMo team.
